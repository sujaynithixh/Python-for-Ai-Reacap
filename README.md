# Python for AI Recap

This repository contains my Python for AI learning recap, practice files, and handwritten-style notes.

This project documents my Python learning journey for Artificial Intelligence. It covers Python setup, VS Code configuration, virtual environments, package installation using pip, Jupyter interactive mode, and basic programming concepts.

- Jupyter interactive mode
- Basic Python syntax
- Print statements
- Running Python files
- Debugging Python errors
